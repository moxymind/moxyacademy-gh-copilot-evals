# TC-001: Locked-out user cannot log in

**Priority:** High
**Preconditions:** User is logged out. Application is open on the login page.
**Test data:** username `locked_out_user`, password `secret_sauce`

| # | Action | Expected result |
|---|--------|-----------------|
| 1 | Enter username `locked_out_user` | Username field contains the value |
| 2 | Enter password `secret_sauce` | Password field is filled (masked) |
| 3 | Click **Login** | Error message "Epic sadface: Sorry, this user has been locked out." is displayed |
| 4 | — | User stays on the login page (inventory is not shown) |
